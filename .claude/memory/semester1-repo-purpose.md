本仓库（NTU/coursework/Semester1）用于归档每个学期各课程的录播转写文本与讲义，并据此生成每周学习笔记。

结构：每课程一个子目录 `<课程编号>/`，每周内容放在 `<课程编号>/weekN/` 文件夹内（含转写 `weekN.txt` 与讲义 PDF），学习笔记汇总在 `<课程编号>/Learning_note.md`（单文件，按周累积）。

用户的目标是**通过录播 + 笔记完成学习，避免实际上课的时间冗余**。因此笔记要能让人自学，尤其第一周开课周的考核信息必须完整准确。整理时以官方课件 PDF 为权威来源，修正转写噪声。
