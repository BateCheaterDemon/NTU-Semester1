# 2. Q1 — Topic 3：Image Enhancement

> **考法**：给你一个小图像（3×3、6×6、9×9）或一个解析形式的 histogram / impulse response，让你**算并画**输出。
> **高频**：histogram、histogram equalization、power/gamma 变换、filter mask、卷积输出、平滑/锐化。

## 2.1 点处理（Point Processing）

点处理 = **逐像素**的灰度映射 `g = T(f)`，与邻域无关。

| 变换 | 公式 | 作用 | 参数 |
|---|---|---|---|
| **Negative（反相）** | `g = L - f` | 反转明暗 | L = 最大灰度 |
| **Log transformation** | `g = c * log(1 + f)` | 压缩**高灰度**、拉伸**低灰度**（适合动态范围大） | c = L / log(1 + L) |
| **Power / Gamma correction** | `g = c * f^γ` | γ<1 提亮暗部；γ>1 压暗 | c 常取 1 |
| **Piecewise linear（contrast stretching）** | 分段线性：`αf`；`β(f−a)+T(a)`；`γ(f−b)+T(b)` | 拉伸关心的灰度区间 | a,b,α,β,γ |

⭐ **考试写法**：先写 `g=T(f)`，再把 f 的所有可能取值**列成表**逐个映射，最后按新值**重画 histogram**。

## 2.2 Histogram 与 Histogram Equalization（重点）

### 2.2.1 定义

- **Histogram** `h(f)`：灰度级 `f` 出现的**像素个数**；
- **Normalized histogram** `p_f(f) = h(f)/n`（n = 总像素数），可视为**灰度 PDF 的离散估计**；
- 性质：`Σ_f h(f) = n`，`Σ_f p_f(f) = 1`。

### 2.2.2 均衡化算法（课件原式，务必按这个写）

```
c(f) = Σ_{t=0..f} p_f(t) = ( Σ_{t=0..f} n_t ) / n        （累积分布 CDF）

g = T(f) = round( ( c(f) - c_min ) / ( 1 - c_min ) * L )
```

- `c_min` = 所有 `c(f)` 中的**最小值**（对应图像里最小的灰度级）；
- `L` = **最大灰度级**（8-bit 图 L=255；2-bit 图 L=3；归一化图 L=1）；
- `round[ ]` 取整；这样得到的 g **近似均匀分布**在 `[0, L]`。

**为什么能均匀**（连续情形，考点）：

```
g = T(f) = ∫_0^f p_f(t) dt        （即 CDF）

p_g(g) = p_f(f) * |df/dg|
d g / d f = p_f(f)   =>   p_g(g) = p_f(f) / p_f(f) = 1
```

⭐ 结论：**CDF 作为变换函数，把任意分布变成均匀分布**。

### 2.2.3 例题 A（2025-26 S1 Q1 原题）：3×3、2-bit

图像（灰度 0–3）：

```
1  2  0
1  3  1
0  2  1
```

**Step 1：histogram**

| f | 0 | 1 | 2 | 3 | 合计 |
|---|---|---|---|---|---|
| h(f) | 2 | 4 | 2 | 1 | 9 |
| p_f(f) | 2/9 | 4/9 | 2/9 | 1/9 | 1 |

**Step 2：CDF**

```
c(0) = 2/9
c(1) = 6/9
c(2) = 8/9
c(3) = 9/9 = 1
c_min = 2/9,  L = 3
```

**Step 3：映射 g = round( (c − c_min)/(1 − c_min) × 3 )**

| f | c(f) | (c−c_min)/(1−c_min) | ×3 | g |
|---|---|---|---|---|
| 0 | 2/9 | 0 | 0 | **0** |
| 1 | 6/9 | (4/9)/(7/9)=4/7 | 12/7≈1.71 | **2** |
| 2 | 8/9 | (6/9)/(7/9)=6/7 | 18/7≈2.57 | **3** |
| 3 | 1 | 1 | 3 | **3** |

**Step 4：输出图像与 histogram**

```
1  2  0        2  3  0
1  3  1   →    2  3  2
0  2  1        0  3  2
```

新 histogram：`h_g(0)=2, h_g(2)=4, h_g(3)=3`（原来集中在 1，现在被"摊开"到 2、3）。

### 2.2.4 例题 B（同题 (b)）：幂变换 `T(f) = (1/3) f²`

逐灰度映射（再量化到 2 bit，即 0–3）：

| f | (1/3)f² | round | g |
|---|---|---|---|
| 0 | 0 | 0 | **0** |
| 1 | 1/3≈0.33 | 0 | **0** |
| 2 | 4/3≈1.33 | 1 | **1** |
| 3 | 3 | 3 | **3** |

```
1  2  0        0  1  0
1  3  1   →    0  3  0
0  2  1        0  1  0
```

新 histogram：`h_g(0)=6, h_g(1)=2, h_g(3)=1`。

⭐ 观察：`γ=2>1` 把**低灰度压得更低**（1→0），这是 **gamma correction 压暗**的典型效果；而均衡化是把 histogram **拉平**，两者目的不同。

### 2.2.5 例题 C（2023-24 S1 Q1）：histogram 用 δ 函数给出

```
P_of(f) = 0.2 δ[f−0.7] + 0.1 δ[f] + 0.3 δ[f−0.8] + c δ[f−1] + 0.2 δ[f−0.9]
```

| 小问 | 做法 |
|---|---|
| (a) 求 f_min、f_max、灰度级个数 | δ 的位置就是**出现过的灰度级**：0, 0.7, 0.8, 0.9, 1 → `f_min=0`，`f_max=1`，共 **5** 个灰度级 |
| (b) 求 c 并画 histogram | 概率和 =1：`0.2+0.1+0.3+c+0.2 = 1` ⇒ **c = 0.2** |
| (c) γ 校正 `g=f²` 后的 histogram | 每个 δ 搬到 `f²`：0→0，0.7→0.49，0.8→0.64，0.9→0.81，1→1；概率不变 ⇒ 新 histogram 在 0(0.1)、0.49(0.2)、0.64(0.3)、0.81(0.2)、1(0.2) |
| (d) 均衡化后的 histogram | `c(f)` 是**阶梯累积**；`g = (c − c_min)/(1 − c_min) * L`；把每个原始灰度的累积概率映射到新灰度，概率随像素**一起搬过去** |

⭐ 关键理解：**变换直方图 = 把每个灰度的"概率质量"整体搬到新灰度**；多个 f 映射到同一个 g 时，概率**相加**。

## 2.3 线性滤波（LSI / Convolution）

### 2.3.1 公式（课件写法）

```
g(x,y) = f(x,y) * h(x,y) = Σ_j Σ_i h(i,j) f(x−i, y−j)
```

- `h` 是 **filter mask（kernel）**，尺寸通常 3×3、5×5；
- 对每个像素，把 mask **翻转后**与邻域**逐点相乘再求和**（数学卷积要翻转；CNN 里实际用 cross-correlation，**不翻转**）；
- 频域：`G(u,v) = F(u,v) H(u,v)`。

### 2.3.2 常见 mask

| 类型 | Mask | 说明 |
|---|---|---|
| **平均（box）滤波** | 全 1/9（3×3） | 平滑、去噪，但**模糊边缘** |
| **高斯滤波** | 权重按距离衰减，总和为 1 | 平滑更自然，**无振铃** |
| **Laplacian（锐化）** | `0 1 0 / 1 −4 1 / 0 1 0` 或 `1 1 1 / 1 −8 1 / 1 1 1` | 二阶微分，**响应边缘**；加到原图可锐化 |
| **Sobel（x 方向）** | `−1 0 1 / −2 0 2 / −1 0 1` | 一阶微分，检测**竖直边缘**（水平梯度） |
| **Sobel（y 方向）** | `−1 −2 −1 / 0 0 0 / 1 2 1` | 检测**水平边缘** |

⭐ **高频-boost（unsharp masking）**：

```
f_hb = A f − f_lp = (A−1) f + (f − f_lp) = (A−1) f + f_hp,   A ≥ 1
```

### 2.3.3 从 impulse response 写 mask（2024-25 S1、2025-26 S2 题型）

**规则**：impulse response `h(x,y) = Σ a_k δ(x−x_k, y−y_k)` 中，**每个 δ 的系数 a_k 就填在 mask 的对应位置**（mask 坐标以中心为 (0,0)）。

**例 1（2024-25 S1）**：

```
h(x,y) = 2δ(x,y) − δ(x,y−1) − δ(x−1,y)
```

- `δ(x,y)` 系数 2 → 中心 (0,0) = 2；
- `δ(x,y−1)`：`y−1=0 ⇒ y=1` → 位置 (0,1) = −1（**下方**一格）；
- `δ(x−1,y)`：`x=1` → 位置 (1,0) = −1（**右方**一格）。

```
mask =   0   0   0
         0   2  -1
         0  -1   0
```

（行 = y，列 = x；中心在 (0,0)）

**语义**：这是一个**方向性边缘检测器**——对**上边/左边**的灰度跳变有响应（因为减的是 y+1、x+1 方向）。所以对"constant background 上的方块"，输出是**方块的右上边界**（一条 L 形边缘），再取绝对值/加偏移可让边缘更清楚。

**例 2（2025-26 S2）**：

```
h = 4δ(x,y) + 2δ(x−1,y) + 2δ(x+1,y)
    − 2δ(x,y−1) − 2δ(x,y+1)
    − δ(x−1,y−1) − δ(x+1,y−1) − δ(x−1,y+1) − δ(x+1,y+1)
```

```
mask =  -1  -2  -1
         2   4   2
        -1  -2  -1         （中心在 (0,0)）
```

- 系数和 = `4+2+2−2−2−1−1−1−1 = 0` ⇒ **zero-sum = high-pass**；
- 对**水平亮线**：上下两行是 −2/−1，中间行是 +4/+2 ⇒ 亮线中间**正响应**、两侧**负响应**（类似"浮雕"）；
- 对**竖直亮线**：同理，只是方向转 90°。

### 2.3.4 卷积输出怎么算（逐点写，别跳步）

以 3×3 mask 为例，输出 `g(x,y)`：

```
g(x,y) = h(-1,-1) f(x+1,y+1) + h(-1,0) f(x+1,y) + ... + h(1,1) f(x-1,y-1)
```

**考试技巧**：

1. 先把 mask 写整齐，**标出中心**；
2. 对每个输出位置，把 3×3 邻域**抄成一个 3×3 小表**；
3. 对应位置相乘再相加（**写出乘加式**，便于拿过程分）；
4. 边界处理：题目若说 "out of the image is constant c"，就**用 c 补边**；若说 zero padding，就补 0。

## 2.4 平滑 vs 锐化 vs 非线性

| 类别 | 代表 | 作用 | 缺点 |
|---|---|---|---|
| **Low-pass（平滑）** | 均值、Gaussian | 去噪、模糊 | **边缘也模糊**；对**椒盐噪声**效果差 |
| **High-pass（锐化）** | Laplacian、Sobel、high-boost | 增强边缘/细节 | **放大噪声** |
| **Order-statistic** | **Median filter** | 去**椒盐噪声**、保边 | 对高斯噪声不如均值 |

**Median 例题**（课件）：邻域 `(10,15,20,20,20,20,20,25,100)` → 排序后中位数 **20** → 把中心像素 15 替换为 20。

⭐ 一句话解释：**线性滤波的输出是邻域的加权平均，所以强噪声（如 100）会被"平均"进结果，且边缘被抹平；中值滤波取排序中间值，离群点直接被丢掉**。

# 3. Q2 — Topic 5：MAP Decision and Classifiers

> **考法**：给 prior + class-conditional PDF（高斯或分段线性）→ 求**决策规则**与**错误率**；或给一个 discriminant function → 推导它等价于 MAP / 最小距离；或推导**加权距离分类器**。
> **核心**：MAP 最小化错误率；高斯假设下判别函数 → Mahalanobis 距离 → 线性分类器。

## 3.1 基本概率量

| 量 | 记号 | 含义 |
|---|---|---|
| **Prior** | `P(ω_i)` | 未看数据前，类 i 的概率 |
| **Class-conditional density** | `p(x ∣ ω_i)` | 类 i 中观测到 x 的密度（likelihood） |
| **Posterior** | `P(ω_i ∣ x)` | 看了 x 后，属于类 i 的概率 |
| **Evidence / mixture** | `p(x) = Σ_i p(x ∣ ω_i) P(ω_i)` | x 的总密度（对所有类相同） |

**Bayes 公式**：

```
P(ω_i ∣ x) = p(x ∣ ω_i) P(ω_i) / p(x)
```

## 3.2 MAP 决策规则

```
Decide ω_k  if  P(ω_k ∣ x) > P(ω_i ∣ x)  for all i ≠ k

即  ω_k = argmax_i P(ω_i ∣ x)
        = argmax_i [ p(x ∣ ω_i) P(ω_i) ]      （分母 p(x) 与类无关，可去掉）
        = argmax_i [ ln p(x ∣ ω_i) + ln P(ω_i) ]   （取对数，单调不变）
```

**为什么最优（必背 3 行）**：

```
P(correct ∣ x) = P(ω_k ∣ x)
P(error ∣ x)   = 1 − P(ω_k ∣ x)
```

选 posterior 最大的类 ⇒ 每个 x 上的 error 最小 ⇒ **积分后的总错误率也最小**。

**总错误率**：

```
p(e) = ∫ p(e ∣ x) p(x) dx
     = 1 − Σ_i P(ω_i) ∫_{R_i} p(x ∣ ω_i) dx
```

其中 `R_i` 是判为类 i 的**决策区域**。二类时：

```
p(e) = P(ω_1) ∫_{R_2} p(x ∣ ω_1) dx + P(ω_2) ∫_{R_1} p(x ∣ ω_2) dx
```

⭐ 直观：**类 1 的样本落进类 2 的区域 + 类 2 的样本落进类 1 的区域**，各自乘 prior。

## 3.3 判别函数（Discriminant Function）

定义 `g_i(x) = ln p(x ∣ ω_i) + ln P(ω_i)`，判给 `argmax_i g_i(x)`。

### 3.3.1 多维高斯情形（课件推导）

```
p(x ∣ ω_i) = 1 / [ (2π)^{d/2} |Σ_i|^{1/2} ] * exp[ −½ (x−μ_i)^T Σ_i^{-1} (x−μ_i) ]
```

取对数：

```
g_i(x) = −½ (x−μ_i)^T Σ_i^{-1} (x−μ_i) − ½ ln |Σ_i| + ln P(ω_i) − (d/2) ln(2π)
```

去掉与 i 无关的常数项：

```
g_i(x) = −½ d_{Σ_i}(x, μ_i) + b_i

d_{Σ_i}(x, μ_i) = (x−μ_i)^T Σ_i^{-1} (x−μ_i)      ← Mahalanobis 距离的平方
b_i = ln P(ω_i) − ½ ln |Σ_i|
```

⭐ **Mahalanobis vs Euclidean**：

```
d_Eu(x, μ) = (x−μ)^T (x−μ)          （各方向等权，受量纲影响）
d_Σ(x, μ)  = (x−μ)^T Σ^{-1} (x−μ)   （按协方差"白化"，尺度无关）
```

1D 时：`d_Eu = (x−μ)²`，`d_Σ = (x−μ)²/σ²`。

### 3.3.2 特例 1：所有类协方差相同 `Σ_i = Σ` → 线性分类器

```
g_i(x) = −½ (x−μ_i)^T Σ^{-1} (x−μ_i) + ln P(ω_i)
       = μ_i^T Σ^{-1} x − ½ μ_i^T Σ^{-1} μ_i + ln P(ω_i)      （丢掉与 i 无关的 x^TΣ^{-1}x）
       = w_i^T x + w_i0
w_i = Σ^{-1} μ_i,   w_i0 = −½ μ_i^T Σ^{-1} μ_i + ln P(ω_i)
```

两类边界 `g_i = g_j`：

```
(μ_i − μ_j)^T Σ^{-1} x − ½(μ_i^TΣ^{-1}μ_i − μ_j^TΣ^{-1}μ_j) + ln[P(ω_i)/P(ω_j)] = 0
```

⇒ **超平面**；但当先验相等且 Σ 相同时，它**垂直于两类均值连线**。

### 3.3.3 特例 2：`Σ_i = σ² I` → 最小距离分类器

```
g_i(x) = −(1/(2σ²)) (x−μ_i)^T (x−μ_i) + ln P(ω_i)
```

若**先验全部相等**，`ln P(ω_i)` 相同 ⇒ 等价于**最小化欧氏距离**：

```
g_i(x) = −‖x−μ_i‖²   ⇒   decide the nearest mean（minimum distance classifier）
```

⭐ 这就是 **template matching** 的理论基础：把每个类的均值当作"模板"，看输入离谁最近。

## 3.4 例题 1：鱼的尺寸（2024-25 S2 Q2）

设定：类 ω1 有 40 条、ω2 有 60 条（⇒ `P(ω1)=0.4, P(ω2)=0.6`）；两个 PDF 是**分段直线**（图给出）。

**决策规则（最小错误率）**：比较 **joint**：

```
P(ω1) p(x ∣ ω1)   vs   P(ω2) p(x ∣ ω2)
```

- 两条曲线的交点 `x*` 就是**阈值**：`x < x*` 判 ω1，`x > x*` 判 ω2（具体方向看哪条在上）；
- **注意先验**：若只比较 `p(x|ω)` 而忽略先验，阈值会偏——这是最常见的失分点。

**错误率**：

```
p(e) = P(ω1) * ∫_{x>x*} p(x ∣ ω1) dx + P(ω2) * ∫_{x<x*} p(x ∣ ω2) dx
```

分段直线 PDF 的积分 = **三角形/梯形面积**：

```
∫ p(x) dx = 面积 = ½ × 底 × 高   （三角形）
```

⭐ 考试时把面积算式写清楚（底、高各是多少），比只写数字更稳。

## 3.5 例题 2：身高判性别（2023-24 S2 Q2）

| 小问 | 做法 |
|---|---|
| (a) 只知道 300 男 / 700 女 | `P(ω1)=0.3, P(ω2)=0.7`，**只比 prior** ⇒ 判**女**；错误率 = `min(0.3, 0.7) = 0.3` |
| (b) 男女各半，均值 1.7 / 1.62 | 先验相同 ⇒ 比较 `p(x∣ω1)` 与 `p(x∣ω2)`；在 1.67 附近**等距**，若方差相同则阈值 = `(1.7+1.62)/2 = 1.66`；x=1.67 ⇒ 判**男**（离 1.7 更近） |
| (c) 300 男 / 700 女，σ1=0.2, σ2=0.3 | 解 `P(ω1) N(x;1.7,0.2²) = P(ω2) N(x;1.62,0.3²)`；这是**二次方程**（方差不同），取合理根作阈值；再积分求错误率 |

**等方差时的闭式阈值**（必背）：

```
x* = (μ1 + μ2)/2 + σ²/(μ2 − μ1) * ln[ P(ω2)/P(ω1) ]
```

- 先验相等 ⇒ 第二项为 0 ⇒ 阈值 = **均值中点**；
- 若 `P(ω2) > P(ω1)`（女多）⇒ 阈值**往男那边移**，更容易判女。

**错误率（等方差、用 Q 函数）**：

```
p(e) = P(ω1) Q( (x*−μ1)/σ ) + P(ω2) Q( (μ2−x*)/σ )
Q(z) = 1 − Φ(z)，Φ 是标准正态 CDF
```

## 3.6 例题 3：最小加权距离分类器（2023-24 S1 Q2）

题目给的判别函数：

```
g_i(x) = − Σ_{j=1..n} (x_j − μ_ij)² / σ_ij² + c_i
```

**理解**：这是**各特征独立、方差不同**的高斯情形（`Σ_i` 为对角阵 `diag(σ_i1²,...,σ_in²)`）。代入高斯判别函数：

```
g_i(x) = −½ Σ_j (x_j − μ_ij)²/σ_ij² − ½ Σ_j ln σ_ij² + ln P(ω_i)
```

题目把 `−½` 缩放、把常数并入 `c_i`，就得到题给形式。**它等价于 MAP（在高斯+独立假设下）**。

**(a) 什么时候它最小化错误率？** —— 当 `p(x|ω_i)` 确实是**独立高斯**、且 `c_i` 取 `−½Σln σ_ij² + ln P(ω_i)` 时，`g_i` 就是对数 posterior（差一个常数），argmax 即 MAP。

**(b) 推导线性分类器**：若**所有类的方差相同** `σ_ij² = σ_j²`（与 i 无关），则

```
g_i(x) = −Σ_j (x_j² − 2x_jμ_ij + μ_ij²)/σ_j² + c_i
```

`−Σ_j x_j²/σ_j²` 与 i 无关，丢掉后：

```
g_i(x) = Σ_j (μ_ij/σ_j²) x_j − Σ_j μ_ij²/(2σ_j²) + c_i'
       = w_i^T x + w_i0
w_i = [μ_i1/σ_1², ..., μ_in/σ_n²]^T
```

⇒ **线性判别函数**（超平面边界）。

**(c) 复杂度对比**：

| 方法 | 训练阶段 | 分类阶段 |
|---|---|---|
| **加权距离（二次）** | 只需估 `μ_ij, σ_ij`（O(nc)） | 每个样本 O(nc) 乘加，**无矩阵求逆** |
| **线性（等方差）** | 同样估 μ、σ（O(nc)） | O(nc)，**更快**（少一次平方） |
| **全协方差高斯** | 估 `Σ_i` 并**求逆**（O(n³)） | 每个样本 O(n²) |

## 3.7 补充：如果题目给的是 joint 而不是 posterior

- **比较 posterior**：`P(ω_i ∣ x)`；
- **比较 joint**：`p(x, ω_i) = P(ω_i) p(x ∣ ω_i)`；
- 两者**只差分母 p(x)**（与类无关）⇒ **决策结果完全相同**；
- ⭐ 计算时**优先用 joint**，避免算 `p(x)`。

## 3.8 错误率的三种算法（按题目给的形式选）

| 题目给的形式 | 算法 |
|---|---|
| 离散 PDF（表格/δ） | 求和：`p(e)=Σ` 落在错误区域的概率 |
| 分段直线 PDF | 求交点 → 算**三角形/梯形面积** |
| 高斯 PDF | 化作 **Q 函数**：`Q(z)=1−Φ(z)`；等方差用 3.5 的闭式 |

> **考法**：给网络结构（层数、神经元数、卷积核、输入尺寸），要求 **① 写出前向表达式 ② 写成矩阵形式 ③ 算参数量/乘加次数 ④ 推导反向传播 ⑤ 解释 CNN/Transformer 的关系**。
> **技巧**：所有答案都先写**维度**，再写**矩阵形状**，最后代入数字。

## 4.1 MLP 前向传播

### 4.1.1 标量形式（两层，2 输入、2 隐层、1 输出）

```
h_1 = f(w_11 x_1 + w_12 x_2 + b_1)
h_2 = f(w_21 x_1 + w_22 x_2 + b_2)
y   = g(v_1 h_1 + v_2 h_2 + c)
```

- `f` 常用 **sigmoid**：`f(s) = 1/(1+exp(−s))`
- `g` 为输出层激活（线性 `g(s)=s` 或 sigmoid）。

### 4.1.2 矩阵形式（必考）

```
o = W^T x + b        （一层）
h = f(W^T x + b)
y = g(V^T h + c)
```

- `x ∈ R^{n_in}`，`W ∈ R^{n_in × n_hidden}`，`V ∈ R^{n_hidden × n_out}`；
- 加深：`x^{(k+1)} = f( W_k^T x^{(k)} + b_k )`，`y = g(W_m^T x^{(m)} + b_m)`。

### 4.1.3 参数量与计算量

```
一层参数量 = (n_in + 1) * n_out      （+1 是每个输出神经元的 bias）
乘法次数 ≈ n_in * n_out
加法次数 ≈ (n_in − 1) * n_out + n_out（含 bias）
```

⭐ 例（2023-24 S1 Q3a）：`x ∈ R^100 → y ∈ R^98`，线性层：

- 参数 `W`：`98×100 = 9800`，bias `98` ⇒ 共 **9898**；
- 乘法 `100×98 = 9800`；加法 `99×98 + 98 = 9800`（每个输出 99 次加法）；
- `输出数 / 参数数 = 98/9898 ≈ 0.0099`。

## 4.2 反向传播（Backpropagation）

### 4.2.1 平方误差 + 链式法则

```
E = ½ (t − y)²
y = g(s),  s = V^T h + c,  h = f(u),  u = W^T x + b
```

**输出层**：

```
∂E/∂y = −(t − y)
∂E/∂s = −(t − y) g'(s)
∂E/∂V = ∂E/∂s * h          （向量形式）
∂E/∂c = ∂E/∂s
```

**隐藏层**：

```
∂E/∂h = ∂E/∂s * V
∂E/∂u = (∂E/∂h) ⊙ f'(u)     （⊙ 逐元素乘）
∂E/∂W = ∂E/∂u * x^T
∂E/∂b = ∂E/∂u
```

**更新**：

```
V ← V − η ∂E/∂V
W ← W − η ∂E/∂W
```

⭐ **只要求更新输出层权重**时（2024-25 S1 Q3d）：

```
Δv_j = η (t − y) g'(s) h_j
Δc   = η (t − y) g'(s)
```

其中 `g'(s) = 1`（线性输出），或 `g'(s) = y(1−y)`（sigmoid 输出）。

### 4.2.2 为什么要非线性激活

- 若 `f` 是线性，多层复合仍是**线性变换** ⇒ 等价于单层；
- 非线性（sigmoid/ReLU）才使 MLP 能逼近任意连续函数（universal approximation）。

## 4.3 CNN 前向与计算（高频）

### 4.3.1 卷积层公式（课件原式）

输入 `P×Q×C`，输出 `P×Q×D`（same padding，stride 1，3×3 核）：

```
y_{i,j,k} = Σ_{n=1..C} Σ_{m=−1..1} Σ_{l=−1..1} w_{l,m,n,k} x_{i−l, j−m, n} + b_k
```

- `w_{l,m,n,k}`：第 k 个 filter、通道 n、偏移 (l,m) 的权重；
- `b_k`：第 k 个 filter 的 bias；
- **每个输出通道 k 都对所有输入通道 n 求和** ⇒ 通道间是**全连接**（这就是 1×1 卷积有意义的根本原因）。

### 4.3.2 输出尺寸与参数量

**Valid convolution（无 padding）**：

```
W_out = (W_in − F)/S + 1
H_out = (H_in − F)/S + 1
```

**Same padding（stride 1）**：`P = (F−1)/2` ⇒ 输出尺寸不变。

**参数量**：

```
F * F * C * D + D        （F×F 核、C 输入通道、D 输出通道；+D 是 bias）
```

**乘加次数**（每个输出点）：

```
F * F * C 次乘法 + (F*F*C − 1) 次加法，再 × D × H_out × W_out
```

### 4.3.3 例题 A（2025-26 S1 Q3）：6×6 图像 + 3×3 核

核（**中心对称**，所以 convolution 与 cross-correlation 结果相同）：

```
-1   1  -1
 1   1   1
-1   1  -1
```

```

2 2 2 0 2 0
2 2 2 0 0 0
0 0 0 0 2 0
```

```
卷积输出：             ReLU 后：
 2   4  -2   4          2   4   0   4
 4   4  -4   4          4   4   0   4
-2  -4   0   0          0   0   0   0
 4   2   0  10          4   2   0  10
```

⭐ 手算示范（左上角输出，对应图像左上 3×3 邻域）：

窗口（图像第 1–3 行、第 1–3 列）：

```

```

```
第 1 行：(-1)*2 + (1)*2 + (-1)*2 = -2
```

### 4.3.4 例题 B（2023-24 S1 Q3）：FC vs Conv 参数量

| 指标 | FC（100→98） | Conv（20 个 3×3 filter，输入 3 通道） |
|---|---|---|
| 参数量 | `(100+1)*98 = 9898` | `20*(3*3*3+1) = 560` |
| 乘法 | `100*98 = 9800` | 每个输出点 `3*3*3=27` 次 |
| 输出/参数比 | `98/9898 ≈ 0.0099` | `(20*H*W)/(560)`（H,W 为输出尺寸） |

⭐ 结论：**卷积用参数共享把参数量降了约 18 倍**，且对平移鲁棒。

### 4.3.5 1×1 卷积 = 通道间的矩阵乘法（高频）

对每个空间位置 `(i,j)`，把所有通道的像素排成向量 `x_{ij} ∈ R^C`：

```
y_{ij} = W^T x_{ij} + b,     W ∈ R^{C × D}
```

- 参数量：`C*D + D`；
- **等价于对每个像素做一次 FC**（通道维度全连接，空间维度共享权重）；
- 把整幅图拉平成矩阵 `X ∈ R^{(HW) × C}`，则 `Y = X W + 1 b^T`，`Y ∈ R^{(HW) × D}`。

**例题（2024-25 S2 Q3）**：`p` 个输入通道、`q` 个输出通道、1×1 卷积：

```
y_{i,j,k} = Σ_{n=1..p} w_{n,k} x_{i,j,n} + b_k
参数量 = p*q + q
乘法 = p*q*(m*n)；加法 = (p−1)*q*(m*n) + q*(m*n)
矩阵形式：Y = X W + 1 b^T，X ∈ R^{(mn)×p}，W ∈ R^{p×q}
```

### 4.3.6 CNN 为什么是"正则化的 MLP"（课件观点）

- 把卷积写成矩阵：**W 是稀疏 + 每行权重相同（Toeplitz/循环结构）**；
- 每个可学习参数**经过所有像素** ⇒ 学到的是**全局通用规则**，不是局部细节 ⇒ **泛化好、抗过拟合**；
- 这也是为什么 filter 用 **3×3 或 1×1**（保证参数覆盖所有位置），并且要 **deep**（堆叠扩大感受野）。

## 4.4 Transformer 与 Attention

### 4.4.1 Q/K/V 的生成（课件原式）

输入矩阵 `X ∈ R^{N×d}`（N 个 token，每行一个 token）：

```
Q = X W_q,   K = X W_k,   V = X W_v
q_i = x_i W_q,  k_i = x_i W_k,  v_i = x_i W_v
```

- `W_q, W_k, W_v` 是**可学习**的线性投影（形状 `d×d_k`）；
- **所有 token 共享同一组 W** ⇒ 等价于 **1×1 卷积**（pointwise）。

### 4.4.2 Attention 计算

```
R = Q K^T                 （N×N，r_ij = q_i · k_j，token 间相似度）
A = softmax(R / sqrt(d_k))   （按行归一化；课件有时忽略 scaling）
Z = A V                   （N×d_v；每个输出是所有 value 的加权和）
z_i = Σ_j a_ij v_j
```

- `a_ij`：token i 对 token j 的**注意力权重**；
- **softmax 按行**：每个 token 对所有 token 的权重和为 1；
- `sqrt(d_k)` 缩放：防止点积过大导致 softmax 饱和、梯度消失。

**多头（Multi-head）**：

```
head_h = Attention(X W_q^h, X W_k^h, X W_v^h)
Z = Concat(head_1, ..., head_H) W_O
```

每个头学**不同的关系**（语法/指代/位置等）。

**残差 + LayerNorm + FFN**：

```
Z' = LayerNorm( Z + Attention(X) )
Y  = LayerNorm( Z' + FFN(Z') )
FFN(z) = ReLU(z W_1) W_2     （pointwise，即 1×1 卷积）
```

### 4.4.3 Attention 的"物理意义"（答题要点）

| 说法 | 含义 |
|---|---|
| **Q 是"查询"** | 当前 token 想找什么信息 |
| **K 是"键"** | 每个 token 能提供什么信息 |
| **V 是"值"** | 每个 token 的实际内容 |
| **QK^T 是相似度** | 两个 token 的相关性（课件称"covariance matrix"式的两两相关） |
| **softmax 归一化** | 变成权重（和为 1） |
| **Z = A V** | 按相关性**加权求和**所有 token ⇒ **全局信息** |

⭐ 与 CNN 的关键区别（老师原话）：**CNN 的权重是训练学出来的；Attention 的权重是由"当前输入"现场算出来的（not learnable）**——所以 Transformer 能对任意输入动态建立全局依赖。

### 4.4.4 CNN 与 Transformer 的关系（2025-26 S2 Q3c 的核心答案）

| 维度 | CNN | Transformer |
|---|---|---|
| **可学习变换** | 卷积核（局部、共享） | `W_q, W_k, W_v`、FFN（**pointwise 1×1 卷积**） |
| **权重来源** | 训练数据学出来 | 投影权重学出来；**attention 权重由输入算出来** |
| **感受野** | 局部，靠堆叠扩大 | **全局**（每个 token 与所有 token 交互） |
| **参数共享** | 空间共享（同一 filter 滑全图） | token 共享（同一 W 作用于所有 token） |
| **本质** | 稀疏+共享的 MLP | 1×1 卷积 + 数据相关的加权聚合 |

⭐ 一句话：**Transformer 的所有可学习模块（Q/K/V 投影、FFN）本质上都是 1×1 卷积；区别在于 attention 的权重不是学出来的，而是由输入动态生成的**。

### 4.4.5 ViT（Vision Transformer）

- 把图像切成 **patch**（如 16×16），每个 patch 拉平后线性投影成 token；
- 加 **position embedding**（否则没有位置信息）；
- 送入标准 Transformer encoder；
- 用 **CLS token** 或全局池化做分类；
- 优点：**全局建模**、大规模预训练后性能强；缺点：**需要大量数据**、计算量大。

## 5.1 生成模型（Video Generation）

### 5.1.1 Discriminative vs Generative

| 维度 | Discriminative | Generative |
|---|---|---|
| **学什么** | `P(y ∣ x)`（决策边界） | `P(x)` 或 `P(x, y)`（数据分布） |
| **输出** | 标签/数值 | **新样本** |
| **例子** | 分类器、回归 | GAN、VAE、diffusion |

### 5.1.2 GAN（Generative Adversarial Network）

两个网络**对抗训练**：

- **Generator G**：输入噪声 `z ~ p_z`，输出假样本 `G(z)`，目标是**骗过 D**；
- **Discriminator D**：输入样本，输出"真/假"概率，目标是**区分真假**。

**目标函数（minimax）**：

```
min_G max_D  E_{x~p_data}[ log D(x) ] + E_{z~p_z}[ log(1 − D(G(z))) ]
```

- D 想**最大化**：真样本 `D(x)→1`，假样本 `D(G(z))→0`；
- G 想**最小化**（等价于最大化 `log D(G(z))`）：让 `D(G(z))→1`。

**为什么能逼近真实分布**：固定 G 时，最优 D 为

```
D*(x) = p_data(x) / [ p_data(x) + p_g(x) ]
```

代回目标函数 ⇒ 等价于最小化 **Jensen-Shannon divergence** `JSD(p_data ‖ p_g)`；当且仅当 `p_g = p_data` 时取最小值 ⇒ **G 的分布逼近真实分布**。

**训练难点**：mode collapse、训练不稳定、需要平衡 G/D。

### 5.1.3 VAE（Variational Autoencoder）

- **Encoder**：`x → q(z∣x)`（通常输出均值 μ、方差 σ²）；
- **Decoder**：`z → p(x∣z)`；
- **Latent space**：低维、连续、近似标准正态的隐空间；**采样 z 后可生成新样本**；
- **Loss**：

```
L = − E_{q(z∣x)}[ log p(x∣z) ] + KL( q(z∣x) ‖ p(z) )
    （重建误差）                （正则：让隐分布接近 N(0,I)）
```

- **Reparameterization trick**：`z = μ + σ ⊙ ε, ε ~ N(0,I)`，使采样可反传。

### 5.1.4 GAN vs VAE（对比表，必背）

| 维度 | GAN | VAE |
|---|---|---|
| **结构** | G + D 两个网络 | Encoder + Decoder |
| **训练** | 对抗、minimax | 最大化 ELBO（重建 + KL） |
| **生成质量** | 更**锐利** | 偏**模糊** |
| **隐空间** | 无显式编码器（除非 BiGAN） | **结构化、连续**，可插值 |
| **稳定性** | 难训练、mode collapse | 稳定、易训练 |
| **目标** | 隐式分布 | 显式近似 posterior |

### 5.1.5 Diffusion（简要）

前向逐步加噪 `x_t = sqrt(α_t) x_0 + sqrt(1−α_t) ε`；反向学习去噪 `ε_θ(x_t, t)`；采样从纯噪声逐步去噪。优点：训练稳定、质量高；缺点：采样慢。

## 5.2 Video Analysis（检测、跟踪、动作识别）

### 5.2.1 Detection & Tracking

- **Detection**：逐帧检测目标（YOLO/Faster R-CNN）；
- **Tracking**：跨帧关联（Kalman filter、Hungarian matching、Siamese tracker）；
- **Tracking-by-detection**：先检测再关联。

### 5.2.2 ReID vs JDE（2024-25 S1 原题）

| 维度 | ReID（Re-identification） | JDE（Joint Detection and Embedding） |
|---|---|---|
| **任务** | 给定一个人，跨摄像头**找回**同一个人 | **检测 + 重识别一起做** |
| **输入** | 裁剪好的行人图 | 整帧图像 |
| **输出** | 特征向量（用于匹配） | 检测框 + 每个框的 embedding |
| **流程** | 两阶段：检测 → 裁剪 → ReID | **单阶段**：一个网络同时输出检测与特征 |
| **优点** | 特征专精、精度高 | **快**（共享 backbone）、适合实时 |
| **缺点** | 慢（两次前向） | 检测与 ReID 目标冲突，需平衡 |

⭐ 一句话：**ReID 是"给图找人"，JDE 是"边检测边提特征"**。

### 5.2.3 Action Recognition

| 方法 | 思路 |
|---|---|
| **Two-stream** | 空间流（RGB 单帧，外观）+ 时间流（optical flow，运动），后期融合 |
| **C3D** | 3D 卷积直接处理时空 volume |
| **LRCN** | CNN 提特征 + LSTM 建模时序 |
| **Hidden Two-Stream** | 用网络**实时生成 optical flow**，省掉预计算 |

⭐ 核心：**外观（spatial）+ 运动（temporal）** 两条信息缺一不可。

### 5.2.4 MEI / MHI（旧卷考过，了解即可）

- **MEI（Motion Energy Image）**：二值运动能量图，表示"哪里动过"；
- **MHI（Motion History Image）**：灰度随时间衰减，**越近的运动越亮**，表示"什么时候动"；
- 缺点：丢失方向/速度细节、对背景运动敏感、需要精确对齐。

## 5.3 Optical Flow（光流）

### 5.3.1 定义

光流 = **3D 运动在图像平面上的 2D 投影**（像素位移场）。

### 5.3.2 三个假设

1. **Brightness constancy**：同一点在相邻帧亮度不变；
2. **Small motion**：位移足够小（可用一阶 Taylor 展开）；
3. **Spatial coherence**：邻域内像素运动相似（Lucas-Kanade 用）。

### 5.3.3 推导（必背）

```
I(x, y, t) = I(x+u, y+v, t+1)
```

一阶 Taylor 展开：

```
I(x+u, y+v, t+1) ≈ I(x,y,t) + I_x u + I_y v + I_t
```

代入 ⇒ **brightness constancy equation**：

```
I_x u + I_y v + I_t = 0
```

- 1 个方程、**2 个未知数 (u,v)** ⇒ **aperture problem（孔径问题）**：只能确定**沿梯度方向的分量（normal flow）**，切向分量未知。
- 数学表述：`∇I · (u,v)^T = −I_t`，解空间是一条**直线**，不是唯一点。

### 5.3.4 Lucas-Kanade

- 假设**邻域内 (u,v) 相同** ⇒ 用 n 个像素建立 n 个方程：

```
[ I_x(p1)  I_y(p1) ] [u]     [ −I_t(p1) ]
[ I_x(p2)  I_y(p2) ] [v]  =  [ −I_t(p2) ]
[      ...         ]         [    ...   ]
```

- 最小二乘解：`[u,v]^T = (A^T A)^{-1} A^T b`；
- 要求 `A^T A` **可逆**（有足够梯度、非平坦区域）。

## 5.4 3D Machine Vision

### 5.4.1 3D 获取方式

| 方法 | 主动/被动 | 原理 | 缺点 |
|---|---|---|---|
| **ToF** | 主动 | 测光/信号往返时间 | 多路径、背景光 |
| **LiDAR** | 主动 | 激光测距 | 贵、ghosting/blooming |
| **Structured Light** | 主动 | 投图案、看变形 | 室外强光失效 |
| **SfM** | 被动 | 多视图特征对应 + 光束法平差 | 计算量大、依赖纹理 |
| **Stereo** | 被动 | 双目视差 | 需标定、弱纹理难匹配 |

### 5.4.2 相机模型

```
x = f X / Z,    y = f Y / Z        （透视投影）
P_camera = R P_world + T           （外参）
```

- `f`：焦距；`Z`：深度；**除以 Z ⇒ 非线性、信息丢失**（单图无法唯一恢复深度）。

### 5.4.3 SIFT vs SuperPoint（2025-26 S1 原题）

| 维度 | SIFT（handcrafted） | SuperPoint（learned） |
|---|---|---|
| **检测** | DoG 尺度空间极值（blob） | CNN 输出 **heatmap**，取局部极大 |
| **描述** | 梯度方向直方图（128 维） | CNN 输出 **descriptor map**（如 256 维） |
| **不变性** | 尺度、旋转（靠金字塔+方向分配） | 从数据中学（需数据增强/训练） |
| **训练** | 无需训练 | **需要训练**（合成数据 + 自监督） |
| **优点** | 可解释、无需数据 | 在弱纹理/光照变化下更强、更快 |
| **缺点** | 对模糊/大视角变化弱 | 依赖训练分布、可解释性差 |

⭐ 关键差异：**SIFT 用人工设计的规则找关键点、用梯度直方图描述；SuperPoint 用网络直接回归"哪里是点"和"点长什么样"**。

### 5.4.4 Stereo Matching（最高频）

#### 几何与视差

```
Z = f * B / d
```

- `B` baseline，`d = x_left − x_right`（disparity）；
- **Z ∝ 1/d**：视差大 ⇒ 近；视差小 ⇒ 远。

#### 步骤（必背四步）

```
1. Feature extraction        左右图提特征（共享权重）
2. Cost volume construction  在视差维度上堆叠匹配代价，H×W×D
3. Cost aggregation          3D CNN / hourglass 聚合上下文
4. Disparity regression       soft argmin / 回归，得到视差图
```

#### Cost volume

- 尺寸 `H × W × D`；`D` = **最大视差搜索范围**（如 192、256）；
- **每个 voxel `(h,w,d)` 的物理意义**：左图 `(h,w)` 与右图 `(w−d,h)` 在视差 d 下的**匹配代价**（特征差的范数/相关性）；
- `D` 太小 ⇒ 近处大视差被截断（**深度范围受限**）；`D` 太大 ⇒ 显存/计算量暴涨、易受噪声干扰。

#### 误差传播（2023-24 S2 原题）

```
Z = f B / d
ΔZ ≈ |dZ/dd| * Δd = (f B / d²) * Δd = Z²/(f B) * Δd
```

⭐ 结论：**深度误差随 Z² 增长**——远处一点点视差误差，会造成很大的深度误差。

#### 三大挑战与对策（2025-26 S1 原题）

| 挑战 | 影响 | 对策（learning-based） |
|---|---|---|
| **Textureless（弱纹理）** | 匹配代价平坦，视差不确定 | 多尺度/大感受野聚合、edge-aware smoothing、**active stereo 投图案** |
| **Occlusion（遮挡）** | 一点在另一图不可见 | **左右一致性检查**（LR consistency）、遮挡 mask、cost volume 中的 robust loss |
| **Repetitive patterns（重复纹理）** | 多个相同匹配，歧义 | 全局上下文聚合（3D CNN/hourglass）、attention、**位置先验** |

#### 系统设计（2025-26 S2 原题）

- **如何定 D**：由**最近工作距离** `Z_min` 决定：`d_max = f B / Z_min`；再考虑分辨率、视场角、显存；D 取略大于 `d_max`；
- **如何省算力**：① 降分辨率/多尺度（coarse-to-fine）；② 用 **1×1 卷积/分组卷积**压缩 cost volume；③ **early exit / 只在 ROI 算精细视差**；④ 稀疏/量化 cost volume；⑤ 轻量 backbone（MobileNet）。

### 5.4.5 Epipolar Geometry（旧卷考过）

```
p'^T E p = 0,   E = [t]_x R                 （标定相机）
x'^T F x = 0,   F = K'^{-T} E K^{-1}        （未标定）
```

- 极线约束：左图一点，右图对应点必在**极线**上；
- **rectification**：把极线变成水平行 ⇒ 只需在一行内搜索。

### 5.4.6 Cross-ratio（交比，旧卷考过）

```
[A,B,C,D] = (|AC|/|BC|) / (|AD|/|BD|)
```

- **投影不变**：任意透视变换下交比不变；
- 用途：从图像中的 3 个已知距离 + 交比，反推第 4 个距离；误差会被放大（对点的定位精度敏感）。

# 6. 公式速查表（考前 30 分钟）

## 6.1 Image Enhancement

```
点处理：g = T(f)
Gamma：g = c f^γ
Log：g = c log(1+f)

Histogram：p_f(f) = h(f)/n
CDF：c(f) = Σ_{t≤f} p_f(t)
Equalization：g = round( (c(f) − c_min)/(1 − c_min) * L )

连续：g = ∫_0^f p_f(t) dt  ⇒ p_g(g) = 1

卷积：g(x,y) = ΣΣ h(i,j) f(x−i, y−j)
Frequency：G = F H
High-boost：f_hb = (A−1)f + f_hp
Median：g = median{邻域}
```

## 6.2 MAP

```
Bayes：P(ω_i|x) = p(x|ω_i) P(ω_i) / p(x)
MAP：argmax_i P(ω_i|x) = argmax_i p(x|ω_i) P(ω_i)
Error：p(e|x) = 1 − max_i P(ω_i|x)
总错误率：p(e) = 1 − Σ_i P(ω_i) ∫_{R_i} p(x|ω_i) dx

Gaussian：p(x|ω_i) = N(μ_i, Σ_i)
g_i(x) = −½(x−μ_i)^T Σ_i^{-1}(x−μ_i) − ½ ln|Σ_i| + ln P(ω_i)
Mahalanobis：d_Σ = (x−μ)^T Σ^{-1}(x−μ)

Σ_i = Σ：g_i = w_i^T x + w_i0, w_i = Σ^{-1}μ_i
Σ_i = σ²I，先验相等：最近均值（minimum distance）

等方差二类阈值：x* = (μ1+μ2)/2 + σ²/(μ2−μ1) ln[P(ω2)/P(ω1)]
p(e) = P(ω1) Q((x*−μ1)/σ) + P(ω2) Q((μ2−x*)/σ)
```

## 6.3 NN / CNN / Transformer

```
FC：y = W^T x + b
参数量：(n_in+1) n_out
两层：y = g(V^T f(W^T x + b) + c)

Backprop（输出层）：Δv_j = η (t−y) g'(s) h_j
隐藏层：δ = (V δ_out) ⊙ f'(u)

Conv：y_{i,j,k} = Σ_n Σ_m Σ_l w_{l,m,n,k} x_{i−l,j−m,n} + b_k
Output：W_out = (W_in − F + 2P)/S + 1
Params：F*F*C*D + D

1×1 conv：y_ij = W^T x_ij + b（等价 FC per pixel）

Attention：Q=XWq, K=XWk, V=XWv
R = QK^T；A = softmax(R/√d_k)；Z = A V
```

```
误差：ΔZ = (Z²/(fB)) Δd
```
